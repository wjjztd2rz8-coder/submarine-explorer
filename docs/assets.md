## 2. Procedural alternatives (don't spend asset-hunting time here)

| Effect                                     | Why procedural wins                                                                                                                                                                                                                                                     |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Marine snow                                | Trivial to fake as a GPU point-sprite system (instanced Points w/ a soft circular alpha texture, drifting + looping in a bounding volume around the camera). No asset search needed — reuse the Kenney particle sprite or a hand-drawn 8×8 radial-gradient PNG.         |
| Caustics                                   | Real caustic footage/texture packs are inconsistent in license and look wrong when tiled. A 2-layer scrolling/rotating Voronoi or Perlin noise fragment shader, modulated by depth and light angle, looks better and is free of licensing concerns.                     |
| Hydrothermal vent smoke/particulate plume  | Use a GPU particle system (curl-noise advected sprites, additive blending, heat-shimmer via a screen-space refraction pass from `postprocessing`) instead of hunting for "smoke" models/animations.                                                                     |
| Coral growth / branching structures        | L-system or space-colonization branching generator gives infinite coral/sponge variety from one algorithm, far more efficient than sourcing dozens of individual coral models — reserve purchased/downloaded coral models only for 2-3 "hero" specimens near landmarks. |
| Bubbles (ballast, ROV thrusters)           | Same point-sprite technique as marine snow, just with rising velocity + a subtle refractive shader; reserve the Freesound bubble _audio_ clips for the accompanying sound only.                                                                                         |
| Underwater god-rays / depth fog / vignette | `postprocessing` pmndrs package effects (GodRays, DepthOfField, Vignette, ColorAverage) — no asset needed.                                                                                                                                                              |

## 3. Licensing & attribution plan

**Policy:** default to CC0/public-domain sources (Poly Haven, ambientCG, Kenney, Quaternius, NASA, most NOAA material, Smithsonian CC0-badged items, Natural Earth). Anything CC-BY goes into `ATTRIBUTION.md` with author + link. Anything CC-BY-NC (MBARI whale-song Freesound uploads, Speedenza creaking-metal ambience, CARI'MAM sperm whale model) is either (a) excluded from a commercial build, (b) replaced with the CC0 equivalent already listed above, or (c) used only after obtaining direct written permission from the rights holder. WHOI imagery requires an explicit license request before any use — treat as off-limits until that's obtained.

Before final ship: re-check every Sketchfab model's license badge on its own page (not the search snippet), and re-confirm the AWS Open Data Registry terms for the MBARI acoustic archive as a possible CC0/CC-BY alternative to the NC-tagged Freesound copies of the same recordings.
