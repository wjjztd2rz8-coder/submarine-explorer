# Phase F asset shortlist

Checked 2026-09-29. Sizes below are **source download sizes**, not GPU memory or final game bundle sizes. Download only the maps and meshes used, then resize, compress, and package them for the mobile tier. Every asset added to the repo still needs an `ATTRIBUTION.md` row under the [Phase F plan](../../plan/PHASE-F-PLAN.md).

**Verification method:** `curl -sI -L <direct URL>` from this worktree. `200` and the final `Content-Type` are recorded below. The ambientCG links are stable `/get?file=…` redirects to ZIPs; the Poly Haven file links come from its [asset-files API](https://api.polyhaven.com/). A `200` HEAD verifies reachability, not artistic fit or the contents of every archive. I inspected the ZIP contents for Ground095A and Metal053C; both contain Color, Displacement, NormalDX, NormalGL and Roughness JPGs, plus AO for ground or Metalness for metal. The other map lists come from the [ambientCG catalog API](https://ambientcg.com/api/v2/full_json?type=Material&limit=3000).

## Decisions for implementation

1. Treat the **pillow basalt, rusticle and manganese** texture rows as material proxies; make their distinct forms in geometry and keep the Journal’s real geology tied to sourced site facts.
2. Sketchfab provides useful **CC BY model references**, but its authenticated downloads and mixed art styles make procedural/hand-built creature and ROV assets safer for the first mobile pass. Verify the downloaded file’s actual format and size before adding it to the manifest.
3. The nine ambientCG ZIPs together are almost **59 MiB** before conversion. Select per-site materials, strip unused maps, and use 1K (or smaller) compressed runtime textures; reserve 2K only for a close hero prop on higher quality tiers.
