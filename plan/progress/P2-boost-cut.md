# P2-boost-cut — remove boost

Owner phone decision, 2026-10-18: boost had no useful perceived effect. Removed the touch dock button, Shift action and gamepad RT action; X remains camera reset. Removed the input state/latch, reserve and recovery timer, progress physics hook, thrust multiplier, power surcharge and effective/config values. There was no displayed boost meter in this checkout; the internal reserve tracking is gone.

Net simpler: one fewer touch target and rebindable action, with no replacement element or setting. Only the boost button and its unused CSS were deleted; no art, layout, size or composition adjustments. How to play and all three controls layouts omit boost; current README/settings/architecture/power docs and CHANGELOG **Removed** agree. Historical playtest reports and previous progress notes remain historical.

The sole gameplay-related source reference left is `LegacyProgress.ts`'s read-only purchase-price evidence. Old saves need that record to recover credit spent on the former boost upgrade; removing it would lose historical credit. It provides no action, tuning or live effect. Existing binding migration already drops retired actions: v1/v2/v3 regressions now include saved boost keys alongside surviving custom and explicitly unbound controls, and verify X remains available for reset.

Deleted boost-only reserve, latch, depletion and hold tests. Retained scan, ballast, camera, Journal, pause, focus, save recovery and conflict/rebinding coverage; generic binding examples now use live actions. Existing capability specs check Shift/RT inactivity with X/Q camera edges, the remaining touch buttons and guide rows, and guide count nine after removing the boost illustration. No assertion deadline, tooling or test configuration was loosened.

Behavioral review: readable and simple controls with no hidden sprint state; normal cruise, descent limits, scanning and discovery rewards remain covered; help no longer promises a removed action; retained touch targets and accessible guide/focus behavior remain covered. Beauty, phone appearance and screenshot acceptance are for Claude; Codex made no visual acceptance claim.
