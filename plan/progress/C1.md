### Fixes after the first browser run (2026-09-23)

- Globe overflowed the viewport top and bottom (start distance 2.9 at 35° fov): `startDistance` 3.5, `dragDegPerPx` 0.2.
- Thick cyan rim: `atmosphereScale` 1.045 → 1.012 (hairline), strength 0.8.
- Snow and ice were the brightest thing on screen: `landDim` 0.34 → 0.22.
- A fast flick (or synthetic pointer events 1 ms apart) spun the globe ~140°: release velocity uses a dt floor of 1/120 s, is capped at `maxFlingDegPerS` (240), and is dropped if the pointer was still for `flingStaleS` (0.1 s) before release. Two unit tests.
- Keys while the globe is open: `stopPropagation` at window capture did not stop other window capture listeners (mission router's Escape-closes-debrief, settings). Now `stopImmediatePropagation` except Tab (FocusTrap still cycles), same pattern as C5 settings.
