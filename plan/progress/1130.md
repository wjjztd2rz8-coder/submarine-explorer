## Plan and root cause

  change only Beebe's scatter geometry/vertex colour, and verify isolation and draw budget.
- `TerrainBiome.ts` requests `pillow`, `rubble`, and `boulder` for Beebe. The

## Changes

- Beebe alone opts into `scatterRock: 'fractured-basalt'`. `Scatter.meshFor`
  builds replacement geometry inside each existing rock InstancedMesh.
- Deterministic jitter and six clipping planes fracture the silhouettes. Corners
  remain duplicated, normals are flat, and UVs are rebuilt by the existing finish
  helper. Pillow/boulder: 80 triangles; rubble: 20. Pillow previously had 140.
- Dark basalt (the apron rubble's `0x2e2d2b`) gets sulfide patches and a small
  sediment dusting on upper faces. Vertex colours cancel the old base instance
  hue while retaining its seeded brightness variation. No placement, density,
  instance buffers, material, shader, texture, collision or scan-target changes.
- Tunings live in `BEEBE_SCATTER_ROCK` in `src/core/config/beebeChimney.ts`.
- Added `beebeScatter.test.ts`: non-Beebe byte snapshots captured BEFORE source
  edits; Beebe old/new placement, colour buffers, materials and three draws match
  across all four tiers; darker colours, nondegenerate triangles, base seating,
  flat unit normals and nonincreasing triangle cost are checked.
- Added a Beebe scatter geometry snapshot. Existing `beebeIsolation` snapshots
  pass without regeneration because the authored chimney/apron meshes are unchanged.
