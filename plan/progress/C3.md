# C3 · Environment presets — integrated, 2026-09-22

`PresetSystem` is wired into `main.ts` after props and POIs are created and
updates after `Atmosphere.update()` each frame. It is available through
`window.__game.presets`. The system selects from `?preset=`, mission
`environment`, or landmark type; content URLs respect the Vite deployment
base. Lost City loads its mission's pale carbonate vent override even on a
free dive. Canyon currents remain on the low tier and are inert in frozen
frames; zero current does not alter ordinary sub velocity. Trench ticks play
the existing hull-creak cue with a caption after audio unlock.

`docs/presets.md` records selection, tunables, performance and limitations.
Nine inspected screenshots are in `docs/img/presets/`. The dedicated browser
spec exercises all eight presets, the Lost City override, low-tier geometry
omission/current, and paused current; unit coverage checks current math and
invalid overrides.

Validation: `npm run build -- --outDir dist-c3`, `npm test`, `npm run test:py`,
and `PW_PORT=4203 PW_OUTDIR=dist-c3 npx playwright test tests/e2e/presets.spec.ts`
passed. The parent run covers the full Playwright suite.

Known rendering limits: vent shimmer uses multiply-blended sprites rather
than full-screen refraction; brine sheen is procedural rather than a true
reflection; the existing caustic projector fades out by 60 m, so reef can
strengthen it only where present. Blake Plateau corals currently inherit the
generic `ridge → seamount` mapping until its content pack specifies a reef
override.
