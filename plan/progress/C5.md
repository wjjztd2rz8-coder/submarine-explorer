# C5 · Settings, save, accessibility: progress

**Done** (not committed):

- `src/ui/Settings.ts`: modal settings screen (O / HUD hint): graphics tier,
  post FX, terrain detail, default sim speed, reduce motion, captions, sonar
  palette, key rebinding with conflict messages, reset settings / bindings.
  FocusTrap; keyboard operable; keydowns stopped at window capture while open.
- `src/main.ts` (`C5` blocks): `Save` at boot; saved tier unless `?tier=`;
  detail strength before the terrain is built; default sim speed; settings
  freeze the game (`frozen` includes `settingsScreen.isOpen`); captions from
  `AudioSystem.captions`; reduce motion -> `CameraRig`; palette -> `Sonar`;
  post FX toggled live; `__game.{save, settings, captions, input}`.
- `src/core/Input.ts`: `loadBindings()` keeps empty (displaced) bindings and
  stops a default key from being re-claimed when another action saved it;
  `resetBindings()` guards `removeItem`.
- `src/ui/HUD.ts`: `setHelpAction()` renders a help item as a button (the
  settings hint).
- CSS under `/* --- C5 --- */`; `docs/settings.md`.
- Reset discoveries now has an in-dialog confirmation, verifies storage removal,
  preserves settings/bindings, and reloads the current URL so discovery views
  rebuild. It rechecks the saved version at confirmation time, protecting a
  newer save written by another tab. Newer versions and failed storage removal
  are reported without claiming the data was erased.
- Apply and reload appears for saved boot-only changes (tier, terrain detail,
  default sim speed), keeps the current mission/URL and honours `?tier=`. A
  failed or protected settings save disables the button and explains why.
- `Save` snapshots the original terrain-detail default before main applies
  saved detail to the live config, so Reset settings restores the real default.
- Restart consequences are explained beside both actions.
